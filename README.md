# API - Sistema de Faturação

API responsável por fornecer os serviços e recursos necessários para o funcionamento do Sistema de Faturação.

O sistema permite gerir de forma centralizada processos relacionados com clientes, produtos, serviços, documentos de faturação, pagamentos e outras operações comerciais.

A API foi desenvolvida para garantir uma comunicação segura e eficiente entre o backend e as aplicações consumidoras, utilizando autenticação baseada em tokens através do Laravel Sanctum.

## Principais funcionalidades

- Autenticação e autorização de utilizadores
- Gestão de clientes
- Gestão de produtos e serviços
- Emissão e gestão de faturas
- Gestão de pagamentos
- Consulta de documentos de faturação
- Proteção de endpoints através de `auth:sanctum`

## Tecnologias

- Laravel
- Laravel Sanctum
- PHP
- MySQL
- REST API
